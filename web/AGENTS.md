# Project Instructions

## Project overview
Đây là dự án frontend sử dụng Next.js.

## Technology
- Next.js
- React
- TypeScript
- Tailwind CSS

## Coding rules
- Ưu tiên TypeScript.
- Không tự ý thay đổi kiến trúc hiện tại.
- Tái sử dụng component trước khi tạo component mới.
- Không sửa API contract nếu chưa được yêu cầu.
- Không xóa chức năng đang hoạt động.
- Giữ giao diện responsive.
- Sau khi thay đổi code, kiểm tra lỗi TypeScript và lint.

## Workflow
1. Đọc cấu trúc project trước khi sửa.
2. Xác định các file liên quan.
3. Đề xuất cách thực hiện nếu thay đổi lớn.
4. Chỉ sửa phần cần thiết.
5. Kiểm tra lỗi sau khi hoàn thành.

## UI requirements
- Giữ đúng design hiện tại.
- Không tự ý đổi màu, font hoặc spacing nếu không được yêu cầu.
- Ưu tiên responsive trên desktop và mobile.
- Component nên được tái sử dụng trong mọi trường hợp.
